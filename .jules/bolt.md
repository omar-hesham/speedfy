## 2023-10-25 - Code Splitting for Main App Components
**Learning:** The initial Vite build output flagged a warning about large chunk sizes ("Some chunks are larger than 500 kB after minification"). This is because `App.tsx` eagerly imports all of the large page components (`SpeedTestEngine`, `ServerSetupGenerator`, `NetworkInterfacesPanel`, `BandwidthCalculator`, `BondingExplainer`, `BondingStatusPanel`, `BondingDashboard`). Because this app renders different pages based on `currentTab`, it's a prime candidate for code splitting using `React.lazy` and `Suspense`. Eagerly loading these components significantly bloats the initial bundle size (703.82 kB in one file).
**Action:** Replace direct imports of route/tab components with `React.lazy()` dynamic imports, wrapping the rendering block in a `<Suspense>` boundary with a fallback loader. This reduces the main initial JS payload and only loads the heavy page chunks when requested by the user, splitting the initial 704 kB chunk into one ~214 kB chunk plus individual chunks for each lazy loaded component.
